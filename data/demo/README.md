# Demo Data Directory

> **NOTICE: DEMO DATA — NOT RESEARCH DATA**

The datasets in this directory are synthetic and for demonstration / implementation verification purposes only.

## Purpose
- To verify that pipeline modules (such as TF-IDF vectorization, cosine similarity, dependency parsers) execute without runtime errors.
- To confirm that inputs and outputs conform to expected types, bounds, and structures.

## Research Integrity Guidelines
- **No Empirical Value:** These examples are not benchmark samples, and no statistical inferences can be drawn from them.
- **No Human Grades:** Human grades are deliberately omitted. Any quantitative evaluation against human ratings will be performed strictly on established, public ASAG benchmark datasets during later experimental stages.
