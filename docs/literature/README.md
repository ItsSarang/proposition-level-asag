# Literature & Foundations

## Primary Base Paper
- **Citation**: Basak, R., Naskar, S. K., & Gelbukh, A. (2019). "Short-answer grading using textual entailment." *Journal of Intelligent & Fuzzy Systems*, 36(5), 4909–4919. DOI: 10.3233/JIFS-179038.
- **Role in Project**: Primary methodological inspiration for Base ASAG (V1). Demonstrates dependency triple extraction, lexical-semantic matching, and textual entailment scoring.

## Benchmark Dataset Paper
- **Citation**: Mohler, M., Bunescu, R., & Mihalcea, R. (2011). "Learning to grade short answer questions using natural language processing and machine learning." *ACL 2011*, 566–575.
- **Role in Project**: Benchmark dataset source for 2,273 active student answers in introductory computer science.
