# Experimental Progression

- **Experiment 1 (Stage 15.2)**: Evaluated V0 (TF-IDF), V1 (Base ASAG), and V2 (Linear Proposed ASAG) on 2,273 records.
- **Experiment 2 (Phase 2)**: Robust proposition representation covering non-clausal structures.
- **Experiment 3 (Phase 3-4)**: Hungarian optimal bipartite matching and bounded horizontal-asymptote scoring.
- **Experiment 4 (Phase 5)**: Severity-aware contradiction analysis with Model D scoring.
- **Phase 6**: AI annotation pilot validating the four-way proposition classification taxonomy (Cohen's kappa = 0.8054).
- **Experiment 5 (Phase 7-8)**: Core paraphrase recovery, non-sentential reference canonicalization, contradiction guards, and Model D2 scoring.
