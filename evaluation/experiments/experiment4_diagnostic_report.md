## 2. Frozen Experiment 4 Definition

Experiment 4 evaluates student short answers through a severity-aware, proposition-level pipeline consisting of the following architectural sequence:

```
Student Answer + Reference Answer + Question
                    ↓
       Base ASAG Pipeline (Stage 10)
  (Tokenization, Spans, Triples, Clausal/Hybrid Matcher)
                    ↓
       Proposition Alignment & Split (Stage 11)
  ┌─────────────────┴──────────────────┐
  ↓                                    ↓
Matched Propositions         Unmatched Propositions
(Base Reference Coverage)              ↓
                       Proposition Representation (Stage 12)
                                       ↓
                       Additional Information Classification (Stage 13)
                       (Contradiction Detector + Epistemic Verifier)
                                       ↓
                       Contradiction Severity Estimation (Phase 4C)
                       (CORE_CONTRADICTION, MODERATE, MINOR, NONE)
                                       ↓
                       Model D Severity-Aware Scoring (Phase 4D)
                                       ↓
                                  Final Grade
```

### Frozen Parameters & Components
- **Scoring Model:** Model D (Core / Additional Decomposition with Gated Compensation).
- **Production Hyperparameters:** $M_{\text{pos}} = 0.30$, $M_{\text{neg}} = 0.40$, $r = 0.50$.
- **Severity Deduction Schedule:**
  - `CORE_CONTRADICTION`: Invalidates core credit ($s_{\text{core}} = 0.0$).
  - `MODERATE`: Deducts $0.50 \times M_{\text{neg}} = 0.20$.
  - `MINOR`: Deducts $0.25 \times M_{\text{neg}} = 0.10$.
  - `UNRESOLVED` / `NONE`: Deducts $0.00$.
- **Domain Knowledge Base:** 3 frozen rules (`PK_NOT_NULL`, `BST_INORDER_SORTED`, `COMPILER_INTERMEDIATE_REP`).
- **Benchmark Corpus:** Mohler et al. (2011) CS short answer dataset (2,273 active records across 81 questions, assignments 1–12).

## 5. Core-Paraphrase Analysis

A central insight from the annotation study is that approximately one-quarter of all unmatched propositions ($N=122, 24.4\%$) are **core reference paraphrases**. These propositions express concepts essential to the question that were intended to match the reference answer, but were rejected by the Stage 7/10 clausal aligner.

### Quantitative Breakdown of Root Causes ($N=122$)

| Root Mechanism | Count | % of Paraphrases | Structural Description |
|---|:---:|:---:|---|
| **Coordination / Conjunction Splitting** | 50 | 41.0% | Compound predicates/objects where one branch is matched and the other is orphaned. |
| **Non-Sentential Reference Fragments** | 41 | 33.6% | Reference answers lacking finite verbs (0 reference clausal triples generated). |
| **Syntactic Slot / Dependency Splitting** | 25 | 20.5% | Clausal vs. nominal expression of the same semantic dependency. |
| **Terminological Synonym Mismatch** | 3 | 2.5% | Domain synonyms failing WordNet / path similarity thresholds. |
| **Comparative / Relational Inversion** | 3 | 2.5% | Converse relational triples ($A < B \iff B > A$). |
| **Total** | **122** | **100.0%** | |

### Concrete Case Studies

#### Case 1: Coordination Splitting (`VALIDATION_0045`, Question 1.1)
- **Question:** *"What is the difference between a class and a structure?"*
- **Reference Answer:** *"In C++, classes default to private members, structs to public."*
- **Student Answer:** *"Classes default to private access for data members and member functions."*
- **Unmatched Proposition:** `(Classes, default to, member functions)`
- **Mechanism:** The aligner matched `(Classes, default to, data members)` to the reference clause, but dropped the conjoined object `member functions`. The system subsequently evaluated this orphaned core concept as `INCORRECT` due to an antonym collision on access specifiers.

#### Case 2: Non-Sentential Reference Fragment (`VALIDATION_0188`, Question 2.1)
- **Question:** *"What is the purpose of a destructor?"*
- **Reference Answer:** *"Deallocates memory and clean up after class object."*
- **Student Answer:** *"To free the dynamic memory allocated by the constructor."*
- **Unmatched Proposition:** `(destructor, frees, dynamic memory)`
- **Mechanism:** The reference answer is a non-finite verb phrase fragment. The clausal extractor extracted 0 canonical reference triples. Consequently, the student's perfectly accurate clausal answer had nothing to align against and was marked 100% unmatched.

#### Case 3: Comparative Inversion (`VALIDATION_0312`, Question 10.5)
- **Question:** *"What is a binary search tree?"*
- **Reference Answer:** *"All values in left subtree are smaller than parent, right subtree greater."*
- **Student Answer:** *"The parent node is always greater than the left child and smaller than the right child."*
- **Unmatched Proposition:** `(parent node, is greater than, left child)`
- **Mechanism:** The student inverted the direction of comparison ($A > B$ instead of $B < A$). The rigid subject-predicate-object slot matcher treated `greater` as antonymous to `smaller`, resulting in an outright `INCORRECT` classification and a core contradiction penalty!

## 7. Incorrect / Contradiction Analysis

In the 500-item sample, Experiment 4 flagged **64 propositions as `INCORRECT`**.

### Breakdown of System `INCORRECT` Flags ($N=64$)

| True AI Label | Count | % of System Flagged | Impact on Student |
|---|:---:|:---:|---|
| **`CORRECT_ADDITIONAL`** | 27 | 42.2% | **Severe Penalty on Valid Work** |
| **`CORE_PARAPHRASE`** | 21 | 32.8% | **Severe Penalty on Correct Core Answer** |
| **`UNCERTAIN`** | 12 | 18.8% | Penalty on ambiguous phrasing |
| **`IRRELEVANT`** | 1 | 1.6% | Penalty on off-topic remark |
| **`INCORRECT` (True Positives)**| **3** | **4.7%** | Justified penalty |
| **Total** | **64** | **100.0%** | **75.0% False Contradiction Rate** |

### Root Mechanisms Driving the 75% False Contradiction Rate

1. **Antonym Collisions on Multi-Valued Categorical Sets:**
   The contradiction detector treats dictionary antonyms (via WordNet) as mutual contradictions. In computer science, terms like `public`, `private`, and `protected` are coordinate members of a set, not binary opposites. When a student explains both access specifiers (e.g. *"public members are accessible everywhere, private members are not"*), the co-occurrence of `public` and `private` triggers a false contradiction.
2. **Converse Relational Comparisons:**
   Comparative predicates (`smaller`/`larger`, `before`/`after`, `above`/`below`) invert when the subject and object are transposed ($A < B \iff B > A$). The Stage 8 entailment engine does not account for argument permutation, treating the converse as a direct semantic contradiction.
3. **Contrastive Subject Conflation:**
   Questions asking for distinctions (e.g. *"What is the difference between an array and a linked list?"*) require students to contrast opposing properties (e.g. *"Arrays have fixed size while linked lists have dynamic size"*). The shallow aligner conflates the two subjects, comparing `dynamic size` against the reference triple for `array` and flagging a contradiction.
4. **Scope Qualifications & Granularity:**
   In C++, passing an array passes a pointer by value, but permits modification of elements (by reference). When students accurately qualify the distinction (e.g. *"the address is passed by value, but elements are passed by reference"*), the slot matcher drops the qualification and flags a polarity conflict.

## 9. Upstream vs. Scoring Failure Analysis

A fundamental question for Experiment 5 is: *Is the failure primarily caused by the scoring formula (Model D), or by upstream representation and alignment?*

### 1. Upstream Representation Failure is the Dominant Bottleneck
The evidence proves overwhelmingly that the failure is **upstream**:
- **Non-Sentential Reference Answers:** **932 out of 2,273 answers (41.0%)** correspond to non-sentential reference fragments. In pure Base ASAG, 100% of these received a base score of 0.0. Even with hybrid representation in Overhauled ASAG, **82.3% remain stuck at 0.0**.
- **Core Paraphrase Loss:** **24.4% of unmatched propositions** are discarded core concepts. When the matcher drops these propositions, the student receives zero base credit for the prompt's primary requirement.
- **Result:** The base score $s_{\text{base}}$ is zero for **76.3% of the entire benchmark**.

### 2. Scoring Model D Compounds the Failure via Gating Deadlock
While the root cause is upstream, Model D actively compounds the pathology through its mathematical formulation:
$$s_{\text{final}} = \max\left(0, \min\left(1, s_{\text{core}} + \mathbf{s_{\text{core}}} \cdot \text{Adj}_{\text{pos}} - \text{Adj}_{\text{neg}}\right)\right)$$

- **Gating Deadlock:** Model D multiplies positive adjustments by $s_{\text{core}}$. If $s_{\text{core}} = 0$, then:
  $$s_{\text{core}} \cdot \text{Adj}_{\text{pos}} = 0 \cdot \text{Adj}_{\text{pos}} = 0$$
- This creates an inescapable deadlock: even if a student writes a brilliant, technically complete answer, if the upstream aligner fails to match the core reference triples ($s_{\text{core}} = 0$), the student can **never** receive additional credit.
- Conversely, negative penalties are un-gated ($-\text{Adj}_{\text{neg}}$), creating a one-way ratchet where grades can only stay at zero or be penalized further.

## 11. Recommended Experiment 5 Changes

To achieve maximum scientific impact while maintaining strict research integrity, Experiment 5 must avoid sprawling, ad-hoc changes. We recommend **three focused, architecturally justified modifications**:

### Change 1: Core Paraphrase Recovery & Clausal-Nominal Bridging (Upstream)
- **Mechanism:** Before routing unmatched student propositions to the additional information layer, pass them through a **Core Paraphrase Recovery filter**.
- If an unmatched proposition shares predicate semantics and core entity arguments with an unfulfilled reference proposition (accounting for coordination splitting and converse relations), it is promoted to **`CORE_PARAPHRASE`** and added to core coverage credit rather than being treated as additional information or misclassified as a contradiction.
- For non-sentential reference answers, project nominal modifier relations into canonical assertion triples to ensure reference propositions exist.

### Change 2: Contradiction Guards for Converses & Multi-Valued Sets (Classification)
- **Converse Inversion Rule:** Check if an apparent contradiction involves comparative predicates (`smaller`/`larger`, `more`/`less`) where subject and object are transposed. If transposed, verify semantic equivalence rather than contradiction.
- **Coordinate Term Rule:** Guard against antonym collisions when terms belong to recognized multi-valued CS enumerations (e.g. `public` / `private` / `protected`; `stack` / `queue`; `array` / `pointer`).

### Change 3: Soft-Gated Compensation Scorer (Scoring)
- Replace the rigid multiplicative gate ($s_{\text{core}} \cdot \text{Adj}_{\text{pos}}$) with a **soft-gated compensation function** (Model D2 or Model E) that permits partial credit recovery when substantial, high-confidence student propositions are demonstrated.

## 12. Candidate Scoring Models for Experiment 5

Two candidate scoring models are proposed to resolve the Model D gating deadlock:

### Candidate 1: Model D2 — Soft-Gated Severity-Aware Scorer
Model D2 preserves the interpretable core/additional distinction and severity penalty hierarchy of Model D, but replaces the hard zero-gate with a smooth piecewise linear floor gate:

$$g(s_{\text{core}}) = \begin{cases} 
\gamma \cdot \frac{s_{\text{core}}}{\tau_{\text{gate}}} & \text{if } s_{\text{core}} < \tau_{\text{gate}} \\
\gamma + (1 - \gamma) \cdot \frac{s_{\text{core}} - \tau_{\text{gate}}}{1 - \tau_{\text{gate}}} & \text{if } s_{\text{core}} \ge \tau_{\text{gate}}
\end{cases}$$

- With $\tau_{\text{gate}} = 0.30$ and $\gamma = 0.25$, an answer with low core alignment ($s_{\text{core}} = 0.10$) can still receive up to $25\%$ of potential additional credit, preventing total floor lockup.
- **Score Equation:**
  $$s_{\text{final}} = \max\left(0, \min\left(1, s_{\text{core}} + g(s_{\text{core}}) \cdot \text{Adj}_{\text{pos}} - \text{Adj}_{\text{neg}}\right)\right)$$

### Candidate 2: Model E — Proportional Propositional Balance Scorer
Model E treats student answers holistically as a pool of validated propositions, scoring them as the weighted harmonic balance between reference coverage and valid student assertion mass:

$$s_{\text{final}} = w_{\text{ref}} \cdot s_{\text{core}} + w_{\text{student}} \cdot \left(\frac{N_{\text{valid}}}{N_{\text{student\_total}}}\right) - \sum \text{SevPenalty}_i$$

- Guarantees that valid student propositions directly contribute to the score regardless of whether the base aligner mapped them to the reference clause.
- Natural resistance to floor compression.

## 16. Research Integrity & Limitations

### Epistemic Separation of Claims
In accordance with the project rules, this diagnostic adheres to strict epistemic standards:
- **PAPER FACT:** Basak et al. (2019) utilize dependency triples and WordNet-based similarity for short-answer scoring. They do not implement proposition-level additional information classification.
- **OUR IMPLEMENTATION DECISION:** The 4-way classification scheme, the epistemic verifier, and the Model D gated severity scorer are original project designs.
- **RESEARCH HYPOTHESIS:** Recovering core paraphrases and removing false contradiction traps will alleviate the floor effect and improve rank correlation with human grading.
- **EXPERIMENTAL RESULT:** Experiment 4 achieved Pearson $r=0.2055$, MAE=3.6288, with 78.4% of grades $\le 0.5$ and a 75.0% false contradiction rate on the 500-item diagnostic sample.

### Methodological Limitations
1. **AI Annotations vs. Human Gold Truth:** The 500-item proposition dataset was labeled by independent AI evaluator instances. While inter-evaluator agreement was high ($\kappa = 0.8054$), human annotation may reveal nuances or disagreement not captured by AI evaluators.
2. **Strict Non-Leakage:** No annotations from the 500-item dataset were used to tune parameters, optimize thresholds, or modify code. They served strictly as an offline observational lens.
3. **Experiment 4 Integrity:** The codebase and benchmark outputs for Experiment 4 remain 100% frozen, reproducible, and intact.
