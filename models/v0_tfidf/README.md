# V0 — TF-IDF Baseline

## Identity
- **Version:** V0
- **Name:** TF-IDF Cosine Similarity Baseline
- **Role:** Non-structural lexical comparison baseline

## Purpose
Establishes a classical bag-of-words lexical similarity baseline by computing TF-IDF vectors of reference and student answers and taking their cosine similarity.
