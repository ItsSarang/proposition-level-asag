Research Architecture & Methodology Documentation

Methodological details, mathematical formulas, and epistemic boundaries of the Automatic Short Answer Grading research engine.

1. Central Research Question

"Can an interpretable proposition-level extension of a classical semantic/dependency-based ASAG system evaluate unmatched student information as correct additional, irrelevant, or incorrect information, and does incorporating this evaluation improve agreement with human grading?"

Epistemic Mandate: This is a formal scientific hypothesis. The presence of interactive examples in this Evaluation Lab does NOT claim or prove that the extension improves human agreement. That question is evaluated empirically via the benchmark metrics on the Mohler ASAG dataset.

2. Four Systems Under Comparison

Version System Name Methodology & Paradigm Unmatched Information Handling
V0 TF-IDF Baseline Bag-of-words token vectorization and cosine similarity. Syntactically unaware. Counted purely as unweighted token overlap.
V1 Base ASAG Simplified Basak-inspired semantic/dependency pipeline. Clausal SPO dependency triples, WordNet path similarity, greedy alignment, reference proposition coverage. Completely discarded. Additions contribute exactly +0.00 to the grade.
V2 Historical Proposed ASAG Stage 14 additive scoring extension over Base ASAG. Computes linear bonuses and penalties. Linear additive adjustment: Base + (0.10 × Correct) - (0.20 × Incorrect).
V3 Current Overhauled Proposed ASAG Hybrid proposition representation (clausal + nominal fragments + infinitives), Semantic Matcher V2 (morphological derivation + 13 curated CS domain equivalences), Hungarian global bipartite alignment, question-aware relevance filtering, property contradiction detection, and horizontal-asymptote bounded scoring. Diminishing marginal returns scoring with strict horizontal asymptote at +0.30, cutting verbosity bias by 50%.

3. Bounded Scoring Mathematics (Model C / V3)

To prevent verbosity inflation ("e-rater gaming") where students write extraneous text to accumulate linear bonuses, the Current Proposed system implements a saturating horizontal-asymptote formula:

bonus(N) = B_max × (r × N) / (1 + r × N)

Where:

  • B_max = 0.30: Maximum allowable positive bonus (30% of question points).
  • r = 0.50: Diminishing rate parameter.
  • For N = 1: Bonus = +0.100
  • For N = 2: Bonus = +0.150
  • For N = 5: Bonus = +0.214
  • For N = 20: Bonus = +0.273
  • As N → ∞, the bonus strictly asymptotically approaches 0.30 and never exceeds it.
  • Irrelevant additions contribute strictly +0.00.

4. Known Limitations & Research Boundaries

  • Non-Clausal Reference Answer Fragments: 40.7% of reference answers in the Mohler dataset consist of nominal fragments rather than complete clausal sentences, requiring hybrid representations.
  • Holistic vs Proposition-Level Ground Truth: The Mohler dataset contains holistic 0–5 marks, not proposition-level gold labels. Proposition classification accuracy must be judged via our double-blind annotation study.
  • Zero LLM Black-Boxes: The entire system uses interpretable NLP (spaCy, WordNet, Hungarian matching, domain lexicons) without calling proprietary LLM APIs or prompt-based grading.
